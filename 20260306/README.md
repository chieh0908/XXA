# 《新笑傲江湖M》六週年慶・獨孤求敗活動網頁 (20260306)

《新笑傲江湖M》(XXA) 六週年慶活動網頁，由艾玩天地（iwplay）代理。全新角色「獨孤求敗」降臨江湖，玩家於活動期間首次登入遊戲帳號即可領取見面禮；活動同步開放「獨孤九劍」見識劍訣抽獎，每日登入或邀請好友皆可獲得見證機會，體驗劍訣特效與傷害數字演出。

- 正式網址：https://xxa.iwplay.com.tw/event/sixth.anniversary.html
- 活動時間：2026/3/6 11:00 ～ 3/31 23:59（UTC+8，網頁開放查詢至 2026/4/30 23:59）

## 遊戲背景

《新笑傲江湖M》是改編自金庸經典武俠小說《笑傲江湖》的正版授權遊戲，玩家加入少林、武當、華山、日月神教等江湖門派，體驗武學修練、門派對抗與 PVP 競技等玩法。

## 活動玩法

- **版頭（KV）**：主視覺搭配 Slogan「血脈覺醒 但求一敗」與副標「3月18日 獨孤求敗席捲中原」，提供前往官網、下載遊戲、FB／YT 社群連結。
- **帳號登入領取禮包（`.sec01`）**：主標「六載風華湧 江湖再少年」，玩家於活動期間首次登入遊戲帳號即可領取「獨孤求敗見面禮」（轉職卷軸）。
- **獨孤九劍・見識劍訣（`.sec03`，核心玩法）**：背景以 Parallax.js 疊出人物與雲霧層的視差景深效果；點擊「見識劍訣」按鈕隨機見證一招劍訣（破氣式／破箭式／破掌式／破索式／破鞭式／破槍式／破刀式／破劍式／總訣式），並以飄浮傷害數字與招式特效演出攻擊值，邀請好友可額外獲得見證機會。另提供「活動規則」按鈕開啟說明彈窗、「查看劍訣」檢視各招式對應獎項一覽。
- **遊戲特色（`.feature`）**：5 張遊戲特色圖以左右箭頭按鈕切換瀏覽，區塊下方附「獎勵查詢」「注意事項」兩顆按鈕。
- **獎勵查詢／注意事項**：點擊後各自開啟對應彈窗，顯示活動日期／名稱／獎勵內容／序號的查詢列表（含複製序號按鈕）與活動注意事項條列。
- **其他彈窗**：通用登入提示（`#eventAlertModal`）、好友邀請（`#invite`）、活動規則（`#eventrules`）。

## 核心技術實作

- **見識劍訣抽獎與傷害數字特效**（`js/invite.js`）：點擊「見識劍訣」按鈕（`#skillB`）後，從破氣式／破箭式／破掌式／破索式／破鞭式／破槍式／破刀式／破劍式／總訣式九個劍訣中隨機抽出一項，先將畫面捲動至劍訣說明文字，再於招式特效區塊內隨機產生 3～5 個位置與飄動時間皆隨機的「飄浮傷害數字」（顯示劍訣名稱＋攻擊值），同時重設並重播兩顆招式特效 GIF 製造出招視覺；延遲約 1.5 秒後彈出「劍訣名稱／攻擊值／獎勵內容」的獲得獎勵彈窗（`#hurt_num`），關閉彈窗後可再次點擊繼續抽獎，直到次數用盡後提示次數不足並自動開啟邀請好友彈窗。
- **邀請好友增加抽獎次數**（`js/invite.js`）：點擊邀請彈窗內的分享按鈕可增加可用抽獎次數，達上限後停止累加。

## 版面規格 / RWD

- 本頁未使用 rem 等比縮放或 `reset.js` 這類裝置偵測機制，版面以 `vw` 彈性字體搭配 Bootstrap 中斷點（1199px／991px／768px／575px…）做結構調整，多數圖像採 PC／手機雙圖源（`<picture>`／`d-none` 切換），非單一圖像自適應伸縮，也沒有強制橫式瀏覽的設計。
