## 遊戲背景

《新笑傲江湖M》是改編自金庸經典武俠小說《笑傲江湖》的正版授權遊戲，玩家加入少林、武當、華山、日月神教等江湖門派，體驗武學修練、門派對抗與 PVP 競技等玩法。

## 活動玩法

- **版頭（KV，`.kv_zone`）**：延續第一階段主視覺與 Slogan「三才試劍・論劍試鋒」，背景以 Parallax.js 做視差效果，KV 按鈕改為可捲動至「神功助力」「一注江湖」兩個本階段區塊。
- **神功助力（`.sec06`，每日抽獎）**：背景同樣以 Parallax.js 做視差效果；玩家每日登入遊戲可獲得一次抽獎機會，邀請好友可額外獲得抽獎機會（單日最多邀請 3 位好友、最高可累積 4 次機會，每日 00:00 重置）；點擊抽獎後以展開卷軸動畫呈現結果，獎項分為絕戰巔峰／名宿巔峰／豪傑巔峰／精英巔峰／新鋒巔峰五個等級。
- **一注江湖（`.sec04-1`，門派押注）**：押注期間可從錦衣衛、聖火、逍遙、梨門、百道、唐門、衡山、五毒、日月、恆山、少林、武當、華山等 13 個門派中，選擇預測會進入公平賽區海選賽前十名的門派進行押注，押中可獲得論劍寶箱；押注截止後顯示「押注已封盤」提示，並提醒玩家記得於賽季結算領取好禮。
- **決賽結果（`.sec04-2`，排行榜領獎）**：開放查看最終門派排行榜（前十名），達成條件的格位可點擊領取獎勵「巔峰福袋」，領取後按鈕轉為「已領取」狀態。
- **遊戲特色（`.feature`）**：同第一階段，5 張遊戲特色圖以左右箭頭按鈕切換瀏覽，區塊下方附「序號查詢」「注意事項」兩顆按鈕。
- **序號查詢／注意事項**：點擊後各自開啟對應彈窗，顯示序號兌換紀錄列表與活動注意事項條列。
- **其他彈窗**：通用提示（`#eventAlertModal`，如未選擇門派時的提醒）、活動規則（`#eventrules`）、門派選擇（`#betModal`／`#sectSelect`）。

## 核心技術實作

- **神功助力卷軸開獎動畫**（`js/invite.js`）：點擊抽獎按鈕後，從獎品清單中隨機抽出一項，先將對應藝術字圖片換到卷軸內的 `.paper .art_text`，按鈕隱藏並顯示卷軸（`#scroll` 加上 `.show`），短暫延遲 200ms 後再加上 `.open` 觸發卷軸展開動畫；展開後延遲 1.2 秒才彈出「獲得獎勵」彈窗（`#hurt_num`），彈窗彈出的同時移除 `.open` 讓卷軸開始收合，待收合動畫（1 秒）結束後才徹底隱藏卷軸並恢復抽獎按鈕，避免彈窗彈出與卷軸收合動畫互相搶拍。
- **門派押注與掃光特效**（`js/demo.js`＋`css/main.css`）：確認下注後，依選擇的門派動態組出對應圖片路徑（`image/sec04/sect_{門派}{_m}.webp`，手機版另帶 `_m` 後綴），以 `<img>` 的 `load`／`error` 事件分流：載入成功即顯示門派圖並把該格背景換成捲軸底圖，若圖片讀取失敗則改顯示古典直排字卡（`.sect_fallback_card`）呈現門派名稱文字，兩種情況都會在該格的 `.team_img_placeholder` 加上 `.has-bet`。`.has-bet` 以 `::after` 偽元素疊一道 `rotate(30deg)` 斜角的半透明白色光帶，預設停在格子左側外（`left: -62%`），滑鼠移入時以 `transition: left 0.4s` 滑到右側外（`left: 188%`）形成掃光效果；賽季結算頁（`.sec04-2`）共用同一套樣式，並在頁面載入時掃描每個排行榜格位是否已有圖片，有的話同樣補上 `.has-bet`，讓結算畫面的門派圖同樣具備 hover 掃光效果。

## 版面規格 / RWD

- 本頁未使用 rem 等比縮放或 `reset.js` 這類裝置偵測機制，版面以 `vw` 彈性字體搭配 Bootstrap 中斷點（1470px／1199px／991px／768px…）做結構調整，多數圖像採 PC／手機雙圖源（`<picture>`／`d-none` 切換），非單一圖像自適應伸縮，也沒有強制橫式瀏覽的設計。
