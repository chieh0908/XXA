# 《新笑傲江湖M》三才試劍・論劍試鋒活動網頁 第一階段 (20260610)

《新笑傲江湖M》(XXA) 年度 1v1 競技活動「三才試劍」聯動活動網頁，由艾玩天地（iwplay）代理。玩家登入遊戲帳號完成網頁預約即可領取競賽贈禮，活躍／回流玩家並有加碼好禮；活動期間累積登入可再領加碼獎勵，邀請好友共闖江湖另有專屬福利。本活動為第一階段（預約／登入／邀請）網頁，第二階段（門派押注／每日抽獎，7/20 開啟）為另一獨立資料夾。

- 正式網址：https://xxa.iwplay.com.tw/event/2026springcup.html
- 活動時間：2026/6/10 12:00 ～ 2026/7/19 23:59（UTC+8，第一階段；同一網址 7/20 起接續上線第二階段內容）

## 遊戲背景

《新笑傲江湖M》是改編自金庸經典武俠小說《笑傲江湖》的正版授權遊戲，玩家加入少林、武當、華山、日月神教等江湖門派，體驗武學修練、門派對抗與 PVP 競技等玩法。

## 活動玩法

- **版頭（KV，`.kv_zone`）**：主視覺搭配 Slogan「三才試劍・論劍試鋒」與副標「2026年度1v1競技正式揭幕 競逐巔峰」，背景以 Parallax.js 做視差滾動效果；三顆 KV 按鈕中僅「立即預約」可正常捲動至預約區塊，另外兩顆（版面上對應圖示為「門派押注」「說明」）點擊僅彈出「7月20日敬請期待」提示，為預留給第二階段功能的入口。
- **立即預約／預約完成（`.sec01`）**：點擊「遊戲帳號登入」後畫面切換為預約完成狀態，依新增／活躍／回流三種玩家身分顯示對應獎勵文案（競賽見面禮／+競賽活躍禮／+競賽回流禮），並顯示「遊戲帳號登出」按鈕可返回預約前畫面。
- **累積登入禮（`.sec02`）**：顯示「您已累積登入 N/14 天」活動期間累積登入進度，累積滿 14 天可領取加碼獎勵。
- **分享邀請禮（`.sec03`）**：提供 FB／LINE／複製連結等分享按鈕，邀請好友組隊參加活動；依成功邀請人數分為多個禮包檔位，達標後按鈕會切換為「已完成」。
- **遊戲特色（`.feature`）**：5 張遊戲特色圖以左右箭頭按鈕切換瀏覽，區塊下方附「序號查詢」「注意事項」兩顆按鈕。
- **序號查詢／注意事項**：點擊後各自開啟對應彈窗，分別顯示序號兌換紀錄列表與活動注意事項條列。
- **其他彈窗**：登入提示（`#eventAlertModal`，提示請先完成遊戲帳號登入）、活動規則（`#eventrules`）。

## 版面規格 / RWD

- 本頁未使用 rem 等比縮放或 `reset.js` 這類裝置偵測機制，版面以 `vw` 彈性字體搭配 Bootstrap 中斷點（1470px／1199px／991px／768px…）做結構調整，多數圖像採 PC／手機雙圖源（`<picture>`／`d-none` 切換），非單一圖像自適應伸縮，也沒有強制橫式瀏覽的設計。
